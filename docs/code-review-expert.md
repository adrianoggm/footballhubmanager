# Code Review Expert Module

This repository contains an additional module at `code-review-expert/`.

## Purpose

`code-review-expert` is a skill package for structured code reviews with focus on:

- SOLID and architecture issues
- Security and reliability risks
- Performance problems
- Error handling and boundary conditions
- Safe code removal planning

## Location

- Module root: `code-review-expert/`
- Main readme: `code-review-expert/README.md`
- Skill definition: `code-review-expert/SKILL.md`
- Checklists: `code-review-expert/references/`

## Notes

This module is independent from runtime backend/frontend execution. It is intended for review workflows.
