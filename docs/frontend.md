# Frontend Guide

## Stack

- React 18
- Vite 5
- Material UI 5

## Key Files

- Package file: `frontend/package.json`
- Source code: `frontend/src`
- Public assets: `frontend/public`

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

## Other Commands

Build production bundle:

```bash
npm run build
```

Preview build locally:

```bash
npm run preview
```
